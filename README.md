الخطوات (5 دقايق):
1) افتح الـ repository بتاع مصاريفي على github.com (نفس الـ repo، ما تعملش واحد جديد).
2) Add file ← Upload files ← اسحب كل محتويات الفولدر ده:
   index.html · sw.js · manifest.webmanifest · الصور الأربعة (icon-192, icon-512, icon-maskable-512, apple-touch-icon) · فولدر fonts
   (الأسماء نفسها فبتحل محل القديم تلقائي).
3) اكتب أي رسالة (Commit message) ← Commit changes.
4) استنى 1-3 دقايق (تبويب Actions فيه "pages build and deployment" لحد ما يبقى أخضر).
5) افتح الرابط من متصفح خاص (Incognito): لازم تلاقي "ميزان".
   (اختياري) امسح ملفات الخطوط القديمة fonts/cairo-* من الـ repo.

اللي بيحصل عند الناس اللي مثبّتين:

- بياناتهم بتفضل (نفس مفتاح التخزين).
